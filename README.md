# Damasus Culberth Portfolio

A Next.js portfolio for Damasus Culberth, covering project work, stack, and contact enquiries.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Contact form

The contact route sends messages through Resend. Copy `.env.example` to `.env.local` and configure:

- `RESEND_API_KEY`
- `CONTACT_EMAIL_FROM`
- `CONTACT_EMAIL_TO`

## Checks

```bash
npm run lint
npm run build
```
